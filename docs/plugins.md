# Плагины Ovygram

Описание аккаунтов, сообщений, файлов, событий и хуков находится в
[документации SDK этапа 3](sdk.md).

Сборка `plugins` для Windows x64 включает CPython 3.13.16 и pybind11 3.0.2.
Архивы закреплены по SHA-256 в `tools/ovygram/python_bundle.py`.
[Манифест CPython для Windows](https://www.python.org/ftp/python/3.13.16/windows-3.13.16.json).
Откройте «Настройки → Плагины» и импортируйте
[пример lifecycle](../tools/ovygram/examples/lifecycle.plugin).
Выберите его в списке и нажмите «Включить». Страница плагина находится
внутри настроек Telegram. На ней появятся переключатель, поле ввода
и список выбора. Изменения применяются кнопкой «Сохранить настройки».
Пример записывает запуски и выгрузки в журнал.

Одиночный `.py` или `.plugin` должен объявить строковые литералы
`__id__`, `__name__`, `__version__`, `__author__`, `__description__`,
а также `__platform__ = "desktop"` и `__desktop_sdk__ = 1`.
Для этой сборки `__requirements__` можно опустить или оставить пустым.
Точка входа объявляет один класс, наследующий `base_plugin.BasePlugin`.

ZIP содержит в корне `plugin.json` с полем `"entry"`, например
`{"entry":"main.py"}`, сам файл и ресурсы. Соседние модули подключаются
относительным импортом, например `from .helpers import format_text`.
Путь к ресурсам начинается от `Path(__file__).parent`.
Предел архива и распакованных данных — 32 МиБ, основного файла — 1 МиБ.

Импорт читает метаданные, а код запускается при включении плагина.
`on_plugin_load` и `on_plugin_unload` вызываются в главном потоке.
`create_settings` возвращает список `Switch`, `Input`, `Selector`
из `ui.settings`. Методы `get_setting` и `set_setting` работают
с общими настройками конкретного плагина, `log` пишет в журнал.
Для обновления выберите файл с тем же ID. Менеджер хранит предыдущую
версию для отката. Обновлённая или восстановленная версия ждёт включения.

Настройки и журнал хранятся в `plugins/` внутри рабочего каталога клиента.
Если предыдущий сеанс оставил аварийный маркер, плагины остаются отключёнными
до нажатия «Возобновить запуск плагинов». Параметр `--disable-plugins`
запрещает запуск плагинов до следующего запуска без этого параметра.
Плагины работают в процессе Telegram, поэтому включайте только доверенные
файлы. Зависший обработчик может заблокировать окно.

GitHub Actions запускает краткую проверку в режиме `plugin-smoke`.
Режим `plugins` повторяет её перед оптимизированной Release-сборкой и упаковкой ZIP.
Для воспроизведения используйте стандартный runner с тем же закреплённым
компилятором и существующими кэшами зависимостей. ZIP использует тестовые
API credentials Telegram, как и базовая сборка этапа 1.
