# Ovygram 0.1.0 на основе Telegram Desktop 7.4.3

**Черновик будущего выпуска:** сборка и приёмка ещё не выполнены.

Первый выпуск Ovygram — Telegram Desktop с плагинами на Python.

## Плагины

- Встроенный Python 3.13 — ставить Python не нужно. Раздел «Настройки →
  Плагины»: импорт, включение, обновление из файла, откат, удаление,
  настройки плагина, журнал, запуск без плагинов после сбоя.
- SDK: аккаунты, сообщения и история, любой запрос Telegram API, файлы,
  события и хуки отправки, запросов, ответов и обновлений.
- Интерфейс: диалоги, окна, страницы в основной колонке, полосы в чате,
  пункты главного меню, меню чата, профиля и сообщения, свои кнопки
  верхней панели и строки ввода, работа со строкой ввода,
  декорации и скрытие чатов, сочетания клавиш, цвета темы, доступ к
  виджетам и сигналам Qt.
- Сторонние библиотеки с PyPI из `__requirements__` ставятся при включении
  плагина.
- Руководство, шаблон проекта и примеры — в папке `docs` и
  `tools/ovygram` исходников.

Плагины работают с правами клиента. Включайте только те, которым доверяете.

## Установка

- **Windows x64:** распакуйте `ovygram-0.1.0-7.4.3-win64-release.zip` и запустите
  `Ovygram.exe`.
- **Arch Linux:** пакет `ovygram-bin` из AUR или архив
  `ovygram-0.1.0-7.4.3-linux-x86_64.tar.xz` (собран под библиотеки Arch).

Ovygram хранит данные отдельно от Telegram Desktop и не обновляется из
официального канала: новые версии ставятся поверх старых, данные
сохраняются.
