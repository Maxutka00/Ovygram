# Состояние Ovygram

Обновлено 5 ноября 2026 года.

Исходники основаны на Telegram Desktop v7.3.5, коммит
`3a2a9a34e833d3243a13787215b8a7cdcf5dc3c3`. Изменения ядра плагинов
и обновление основы объединены без конфликтов Git.

## Подготовлено в исходниках

- Встроенный CPython 3.13.16 через pybind11 3.0.2, менеджер плагинов в
  штатных настройках Telegram, импорт, включение, отключение и откат.
- SDK 2: аккаунты, загруженные данные и история, отправка, редактирование,
  удаление и пересылка сообщений, загрузка и скачивание файлов.
- События сообщений, аккаунтов и чатов; прикладные RPC-хуки и обработка Updates.
- Генератор 2578 TL-конструкторов и методов, кодек и объявления для редактора.
- Управляемый asyncio, таймеры, фоновые операции и диспетчер главного потока.
- [Документация SDK](sdk.md) и пять [примеров](../tools/ovygram/examples).

## Проверка

Предыдущая личная сборка ядра плагинов на основе v7.3.3 проверялась на Windows.
Это не проверка новой версии Ovygram. Для переименованных исходников v7.3.5
прошли 44 локальных Python-теста на CPython 3.13.16; один тест нового нативного
хоста пропущен, поскольку его DLL не собиралась.

Сейчас нет собранного и проверенного Ovygram с SDK 2. Следующим шагом должны
стать компиляция C++, запуск portable-пакета в отдельном профиле и проверка
аккаунтов, хуков, файлов и выгрузки плагинов в настоящем Telegram-сеансе.
До такого запуска нельзя считать этап SDK 2 завершённым.

## Перед публичным выпуском приложения

Нужны собственные API credentials, отдельная иконка и окончательная проверка
названия приложения, уведомлений Windows, сохранности данных и совместимости
плагинов. Исходники содержат ресурсы upstream для дальнейшей адаптации;
открытие репозитория не является выпуском готового приложения.

Поддержка сторонних Python-зависимостей, расширенные UI-панели и общий мост
к внутренним Qt/C++-объектам относятся к следующим этапам разработки.
