# Чек-лист проверки интерфейса плагинов

Проверка этапа 4 и исправлений аудита в собранном клиенте. Примеры лежат в
`tools/ovygram/examples`; каждый импортируется в «Настройки → Плагины» и
включается вручную. После каждого блока выключите плагин и убедитесь, что
всё, что он менял, вернулось.

Удобно держать открытым журнал: `plugins.log` в каталоге профиля.

## Окна и холст — `ui_widgets`

- [ ] Окно открывается, содержимое прокручивается, холст рисуется.
- [ ] Кнопки и переключатели вызывают обработчики, поле ввода — `on_change`.
- [ ] Диалог закрывается кнопкой «Закрыть»; повторное открытие работает.
- [ ] Выключение плагина закрывает окно и диалог.

## Полоса в чате — `chat_bar`

- [ ] Полоса появляется над сообщениями нужного чата, текст по центру.
- [ ] Переход в другой чат и обратно: полоса на месте, клиент не падает.
- [ ] Уход в настройки и возврат в чат: полоса на месте (исправление MED-01).
- [ ] Панель эмодзи и выпадающие меню чата не закрываются полосой.
- [ ] Кнопка отправки сообщения: сообщение сразу видно в чате.

## Раздел — `section`

- [ ] Главное меню → «Раздел плагина» открывает страницу вместо чата.
- [ ] «Нажать» увеличивает счётчик, «Закрыть» возвращает к прежнему экрану.
- [ ] Открыть раздел, перейти в чат через поиск, нажать «Назад»: раздел
      возвращается с тем же счётчиком.
- [ ] Открыть раздел, выбрать чат в списке: в журнале «Раздел закрыт».
- [ ] Узкое окно (одна колонка): раздел открывается и закрывается.
- [ ] Выключение плагина при открытом разделе возвращает к прежнему экрану.

## Меню — `menus`

- [ ] Главное меню: «Аккаунты Ovygram» показывает список аккаунтов.
- [ ] «⋮» в чате и правый клик по чату в списке: «Скопировать ID чата».
- [ ] Правый клик по сообщению: «Скопировать текст», «Цитировать в поле
      ввода»; пункты отделены разделителем.
- [ ] После выключения плагина пунктов нет.

## Кнопки в панелях — `panel_buttons`

- [ ] В верхней панели видна «★», перед полем ввода — «+»; штатные кнопки,
      заголовок чата и поле ввода не перекрываются.
- [ ] Нажатие открывает диалог с аккаунтом, чатом и названием панели;
      подсказка кнопки обновляется. Проверить два аккаунта и два окна.
- [ ] Уменьшение ширины, масштаб интерфейса и RTL: лишние кнопки скрываются,
      отправка, вложения и ввод текста остаются доступны.
- [ ] Поиск, выделение сообщений, запись голосового, переход к настройкам
      и возврат: кнопки скрываются и появляются в подходящем режиме.
- [ ] Временным плагином проверить `chat`/`kinds`, приоритет нескольких
      кнопок, `update`, `enabled=False`, `hide`/`show` и `remove`.
- [ ] Выключение и повторное включение удаляет кнопки во всех окнах,
      восстанавливает место и не дублирует обработчики.

## Элементы Telegram — `top_bar`, `widget_inspector`

- [ ] Кнопка звонка скрыта без пустого места, в канале не появляется.
- [ ] Перехват поиска показывает диалог; выключение возвращает поиск.
- [ ] Скрытие элементов строки ввода срабатывает сразу при открытии чата
      (исправление HIGH-09).
- [ ] Цвета меняются и возвращаются при выключении.
- [ ] Ctrl+Shift+I открывает дерево виджетов, кнопка копирования работает.

## Список чатов и сообщения — `chat_style`, `highlight`

- [ ] Отметка открытого чата в списке, Ctrl+Alt+U переключает стиль.
- [ ] Сообщения со словом подсвечены; при свайпе для ответа и в режиме
      выделения подсветка двигается вместе с пузырём (MED-05).
- [ ] Ctrl+Alt+H скрывает открытый чат; поиск его находит.
- [ ] Скрыть **закреплённый** чат, переставить другие закреплённые, вернуть
      чат: он снова закреплён на своём месте, в том числе на телефоне
      (HIGH-07).

## Строка ввода — `math_autocomplete`

- [ ] `1+3=` предлагает `4` выделением, пробел принимает, Backspace убирает
      результат целиком.
- [ ] То же с эмодзи перед выражением: `😀 2*5=` → `10` (HIGH-06).
- [ ] Обычный набор текста не меняется.

## Хуки и отправка — `text_hooks`, `rpc_hooks`

- [ ] Текст, изменённый хуком, остаётся изменённым после отправки.
- [ ] Отмена отправки текста хуком: сообщения нет, один тост.
- [ ] Отмена отправки фото, альбома и пересылки: сообщения нет, нет
      «CLIENT_PLUGIN_CANCELLED» и красной иконки (HIGH-08).
- [ ] `after_rpc` с фильтром по одному методу: остальные запросы работают
      как обычно, клиент не тормозит (HIGH-11).
- [ ] Ошибка в хуке `before_updates`: новые сообщения всё равно приходят.

## Сообщения из плагина

- [ ] `client.delete_messages` убирает сообщения из чата сразу (MED-03).
- [ ] Добавление подписи хуком к фото без подписи видно в чате (MED-02).

## Qt — `native_events`

- [ ] Открытие меню, диалогов и окон пишется в журнал.
- [ ] Новое сообщение в другом чате меняет заголовок окна, это видно в журнале.
- [ ] Ctrl+Alt+N показывает список слотов главного окна.
- [ ] После выключения плагина записи в журнал прекращаются.

## Зависимости — `qr_code`

- [ ] Включение плагина показывает «Устанавливаются зависимости», страница
      обновляется сама, после установки плагин запущен.
- [ ] Меню сообщения → «QR-код текста» показывает картинку.
- [ ] Второй плагин с несовместимой версией той же библиотеки: ошибка pip
      на его карточке, первый плагин работает.
- [ ] Плагин, которому нужна другая версия уже загруженной библиотеки:
      сообщение о перезапуске; после перезапуска плагин запущен.
- [ ] Без сети: понятная ошибка, клиент не зависает.
- [ ] Windows: установка Pillow проходит (бинарный wheel `win_amd64`).

## Выгрузка и восстановление

- [ ] Включить и выключить каждый пример несколько раз подряд.
- [ ] Выключить плагин во время работы его фоновой задачи, которая
      открывает окна: после выключения окон не остаётся (HIGH-10).
- [ ] Выход из клиента с открытыми окнами, разделом и полосами — без падения
      (CRIT-01).
- [ ] Выход из клиента с WebProxy — без зависания (HIGH-03).
- [ ] Обычный запуск после чистого выхода не включает режим восстановления.
