# Обновления основы Telegram

Текущая основа: Telegram Desktop v7.3.5, коммит
`3a2a9a34e833d3243a13787215b8a7cdcf5dc3c3`.

Репозиторий начинается с одного снимка исходников. История upstream не является
его предком, поэтому обычный `git merge` с новой версией Telegram потребует
специальной обработки. Не добавляй старую историю в публичные ветки автоматически.

При обновлении сначала получи выбранный официальный тег и проверь его коммит.
Для трёхстороннего слияния используй текущий закреплённый upstream-коммит как
явную базу: `git merge-tree --write-tree --merge-base=<old-upstream> HEAD <new-upstream>`.
Проверь конфликты, подмодули и рецепты зависимостей. Результат сохраняй отдельным
коммитом поверх текущей ветки без добавления upstream в родители этого коммита.
Обнови закреплённый SHA в сборочных инструментах и документации.

После слияния повторно проверь мост Python, хуки, упаковку Ovygram.exe,
права Actions и лицензионные уведомления. Python-тесты не заменяют компиляцию
и проверку приложения. Длительную сборку запускай только по отдельному решению.
