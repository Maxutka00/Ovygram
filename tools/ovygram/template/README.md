# Шаблон плагина Ovygram

Готовый проект плагина из нескольких файлов: метаданные, настройки,
событие, пункт меню и отдельный модуль.

## Начало

1. Скопируйте папку `template` и переименуйте её.
2. В `main.py` замените `__id__` на свой (латинские буквы, цифры и `_`, до
   25 символов, например `yourname_weather`) и тот же ID в `plugin.json`,
   а также имя, автора и описание. `__release__ = True` — плагин публичный:
   после проверки он попадёт в репозиторий плагинов.
3. Соберите архив: `python pack.py` — получится `dist/<id>.ovyzip`. Этот же
   файл отправляется боту на проверку.
4. В Ovygram: «Настройки → Плагины → Импортировать плагин», выберите архив,
   включите плагин.
5. После правок снова выполните `python pack.py` и на странице плагина
   нажмите «Обновить из файла». Настройки сохраняются.

Плагин из одного файла тоже возможен: переименуйте `main.py` в
`<id>.ovyplugin`, уберите относительные импорты и импортируйте его напрямую.

## Автодополнение

`pyrightconfig.json` указывает редактору (VS Code с Pylance, Pyright,
PyCharm с плагином Pyright) на SDK в этом репозитории. Если шаблон лежит в
другом месте, укажите в `extraPaths` путь к SDK:

- в репозитории Ovygram — `Telegram/PluginSDK`;
- в установленном клиенте — папка `python/sdk` рядом с программой.

SDK поставляется с `.pyi`-файлами, поэтому редактор знает типы `desktop.ui`,
`desktop.client` и TL-объектов `desktop.tl`.

## Структура

| Файл | Назначение |
| --- | --- |
| `plugin.json` | ID и точка входа архива: `{"id": "example_template", "entry": "main.py"}` |
| `main.py` | Метаданные и класс плагина |
| `helpers.py` | Пример модуля, подключается как `from .helpers import ...` |
| `pack.py` | Сборка архива, в архив не попадает |

В архив попадают все файлы, кроме `pack.py`, `pyrightconfig.json`,
`README.md` и `dist`. Ресурсы читайте от `Path(__file__).parent`.
