# Примеры плагинов

Каждый пример — рабочий плагин: импортируйте файл в «Настройки → Плагины» и
включите. В начале каждого файла написано, какой приём он показывает.

## Полезные плагины

| Пример | Что делает | Чему учит |
| --- | --- | --- |
| [`currency_rates`](currency_rates.plugin) | Курсы валют на странице из главного меню | HTTP стандартной библиотекой в фоне, кэш на диске, периодический таймер, `ui.Section` |
| [`weather`](weather.plugin) | Команда `/погода Город` присылает погоду в чат | Библиотека с PyPI (`requests`), команда через хук и фоновую задачу, чат по `InputPeer` |
| [`wiki_summary`](wiki_summary.plugin) | «Что это?» в меню сообщения — справка из Википедии | Асинхронный пункт меню, REST API, экранирование текста в URL, диалог с действиями |
| [`rss_feed`](rss_feed.plugin) | Новые записи RSS или Atom ленты в Избранное | Фоновый опрос, разбор XML, состояние между перезапусками, защита от лавины сообщений |
| [`clean_links`](clean_links.plugin) | Убирает `utm_*`, `fbclid`, `si` из отправляемых ссылок | Быстрый `before_send`, `DEFAULT` без изменений сохраняет форматирование |
| [`away_reply`](away_reply.plugin) | Автоответ в личных чатах | Событие `new_message`, фильтрация, ограничение частоты, настройки по аккаунтам |
| [`chat_stats`](chat_stats.plugin) | Самые активные участники и активность по часам | Постраничная история, прогресс в окне, остановка при закрытии, графики на `Canvas` |
| [`reminders`](reminders.plugin) | «Напомнить через…» в меню сообщения | Несколько пунктов меню, JSON с атомарной записью, один таймер вместо многих |
| [`qr_code`](qr_code.plugin) | QR-код текста сообщения | Бинарная библиотека с PyPI (Pillow) |
| [`math_autocomplete`](math_autocomplete.plugin) | Подсказка результата `1+3=` в строке ввода | Строка ввода, сочетания клавиш, безопасный разбор выражений через `ast` |

## Правила, которым следуют примеры

- **Не блокируйте главный поток.** Сеть, диск и долгие вычисления — в
  `async def` и `run_in_background`. Хуки синхронные: в них только быстрая
  локальная работа, остальное — через `self.run_async(...)`.
- **Сеть ненадёжна.** Таймаут у каждого запроса, понятный `User-Agent`,
  ошибки показываются пользователю или пишутся в журнал, плагин не падает.
- **Ничего не меняйте зря.** Хук без изменений возвращает `HookResult()`;
  новое значение `message.text` сбрасывает форматирование.
- **Не устраивайте лавину.** Автоответы ограничены по частоте, первая
  проверка ленты только запоминает записи, за раз отправляется немного.
- **Состояние — в каталоге данных.** `get_plugin_data_dir()` и атомарная
  запись (временный файл и `replace`); настройки пишутся в главном потоке.
- **Всё снимается при выгрузке само.** Хуки, подписки, пункты меню, окна и
  таймеры принадлежат плагину, отдельно их убирать не нужно.

Подробности — в [руководстве](../../../docs/guide.md).
