# Безопасность и личные данные

Ovygram — экспериментальный неофициальный клиент. SDK 2 ещё требует
проверки собранного приложения. Наличие исходников и успешных Python-тестов
не означает, что клиент прошёл аудит безопасности.

## Плагины

Python-плагины выполняются внутри клиента с правами его процесса. Они могут
получить доступ к данным аккаунтов, файлам и сети. Разрешение или отключение
плагина не является системой изоляции. Не устанавливай неизвестные плагины
в профиль с важными данными без предварительного изучения кода.

## Отчёты об ошибках

Не прикладывай к публичным Issues и pull requests:

- `tdata`, файлы сессий, коды входа и пароли двухэтапной аутентификации;
- API hash, токены GitHub или ботов, приватные ключи и сертификаты;
- содержимое личных переписок и неочищенные логи или дампы памяти.

Для публичного описания используй отдельный тестовый профиль и искусственные
данные. Проверь содержимое каждого приложенного файла. Описывая уязвимость,
не публикуй действующий секрет или способ атаки на чужой аккаунт.

## Публикация и сборки

GitHub Actions для компиляции запускается только вручную и получает
`contents: read`. Изменения workflow от сторонних участников проверяются
до запуска. Не включай выдачу секретов коду из непроверенного pull request.

`.gitignore` предотвращает случайное добавление известных файлов профиля,
но не удаляет их из уже существующей истории Git. Перед открытием репозитория
или распространением сборки проверяются также история, логи и артефакты.
